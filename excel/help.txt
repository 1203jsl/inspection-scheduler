검수일정 관리 (엑셀 매크로판) 사용 안내

■ 처음 한 번: 매크로 넣기 (약 5분)
1. 받은 압축 파일을 오른쪽 클릭 → 속성 → 아래쪽 '차단 해제'에 체크 → 확인. (인터넷에서 받은 파일은 이걸 안 하면 매크로가 막힙니다)
2. 압축을 풀고 '검수일정관리.xlsx'를 엽니다.
3. Alt + F11 을 눌러 VBA 편집기를 엽니다.
4. 편집기 메뉴 [파일] → [파일 가져오기] → 'modInspection.bas' 선택. 한 번 더 [파일 가져오기] → 'clsAppEvents.cls' 선택.
5. 편집기를 닫고(X), 엑셀 [파일] → [다른 이름으로 저장] → 파일 형식 'Excel 매크로 사용 통합 문서 (*.xlsm)' → 공유 폴더(Y: 검수 폴더)에 '검수일정관리.xlsm'으로 저장.
6. 파일을 닫았다가 다시 엽니다. 위쪽 노란 줄의 [콘텐츠 사용]을 누르면 버튼과 원본·첨부·백업 폴더가 자동으로 만들어집니다.
   버튼이 안 보이면 Alt + F8 → 'SetupNow' 실행.
7. [설정] 시트에서 보내는 사람 이름·웹메일 주소 등을 넣고, [검수자] 시트에 검수자를 등록합니다.

■ 함께 쓰기
- 파일 하나를 Y: 공유 폴더에 두고 같이 씁니다. 먼저 연 사람만 수정할 수 있고, 나중에 연 사람은 '읽기 전용'으로 열립니다.
- 수정이 끝나면 저장하고 파일을 닫아 주세요. 저장할 때마다 [백업] 폴더에 복사본이 남습니다.

■ 업무 흐름
1. [홈] → [업체 신청 양식 만들기] → 저장한 양식을 업체에 메일로 보냅니다.
2. 업체 회신 엑셀이 오면 [홈] → [엑셀 가져오기] → [파일 선택] → 판정·사유 확인 → [가져오기 확정]. 신청번호가 자동으로 붙습니다.
   - 업체가 신청번호를 적어 다시 보낸 행은 '수정'으로 판정되어 기존 건을 고칩니다.
   - 원본 엑셀은 [원본] 폴더에 날짜별로 복사됩니다.
3. [검수목록]에서 검수일·시간·장소·검수자를 정하고 [상태]를 '확정'으로 바꿉니다.
   - 필수 칸이 비었거나 충돌 조건에 걸리면 알려 줍니다. 충돌이 있어도 사유를 적고 진행할 수 있습니다(설정에서 끌 수 있음).
   - 확정한 건의 일정을 바꾸면 사유를 묻고 '변경됨'이 됩니다. 다시 '확정'으로 바꾸면 재확정입니다.
   - 취소는 [상태]를 '취소'로 바꾸고 사유를 적습니다.
4. 검수가 끝나면 [결과] 칸에 합격/불합격을 고릅니다. 불합격이면 사유를 묻습니다. 상태가 '검수완료'가 됩니다.
5. 메일: [검수목록]에서 행을 고르고 [선택 건 메일 작성] → [메일] 시트에서 확인 → [본문 복사] 등으로 웹메일에 붙여넣어 보냄 → [보냄으로 기록].
   - 상태에 맞는 메일(접수·확정·변경·취소·합격·불합격)이 자동으로 골라집니다. 같은 업체 확정·접수는 한 통으로 묶입니다.
6. 결과 통보 기한: 검수일 다음날부터 7일(설정에서 변경) 안에 결과 메일을 보내야 합니다. 안 보낸 건은 [처리 필요]에 남고, 기한이 지나면 빨간색이 됩니다.
   [홈] → [결과 통보 요청 메일 작성]으로 담당 검수자에게 보낼 메일을 만들 수 있습니다.
7. [홈] → [검수자 알림 메일 작성]: 오늘·내일(설정) 배정된 검수를 검수자별 메일로 만듭니다.

■ 화면
- [홈]: 오늘·이번 주 검수, 충돌 경고, 처리 필요 목록, 다가오는 검수. 신청번호 더블클릭 = 상세.
- [검수목록]: 모든 건. 머리글의 ▼ 필터로 업체·프로젝트·검수 품목·상태·날짜(날짜 필터 → 사이)를 거를 수 있습니다. 회색 머리글 칸은 자동으로 채워집니다.
- [달력]: 월별 일정. 날짜 칸 더블클릭 = 그날 검수만 목록에 표시.
- [상세]: 신청 원본과 현재 값 비교, 협의 기록, 첨부, 메일 기록, 변경 이력.
- [협의기록]·[첨부]·[메일기록]·[변경이력]·[신청원본]: 자동으로 쌓이는 기록입니다(수정 잠금).
- [업체]: 가져오기 때 자동으로 추가·갱신됩니다. [검수자]·[설정]·[메일양식]: 직접 고칩니다.

■ 되돌리기
- 잘못 저장했으면 [홈] → [백업 폴더 열기] → 원하는 시각의 파일을 열어 내용을 확인하고, 그 파일을 '검수일정관리.xlsm' 이름으로 다른 이름 저장해 바꿉니다(바꾸기 전에 지금 파일은 다른 이름으로 보관).

■ 문제가 생기면
- 버튼을 눌러도 반응이 없거나 자동 기록이 멈추면: 파일을 닫았다 다시 열고 [콘텐츠 사용]을 누르세요.
- 매크로 오류 창이 뜨면 [종료]를 누르고, 창의 내용과 노란 줄로 표시된 코드 위치를 캡처해 개발 담당에게 알려 주세요.
